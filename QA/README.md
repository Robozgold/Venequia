# Calidad y pruebas (QA)

Estructura propuesta:
- `test-plans/` — planes de prueba por capítulo/sistema.
- `bug-reports/` — incidencias reproducibles.
- `regression/` — pruebas repetibles después de cambios.
- `playtest-notes/` — observaciones de sesiones de juego.

Toda incidencia debería incluir versión/commit, pasos para reproducir, resultado esperado, resultado observado, severidad y evidencia.
