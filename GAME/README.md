# Incorporación del proyecto RPG Maker MZ

Esta carpeta está reservada para una copia controlada del proyecto. **Todavía no contiene el juego.**

## Antes de incorporar archivos
1. Cerrar RPG Maker MZ.
2. Duplicar la carpeta completa del proyecto y guardar otra copia fuera de GitHub.
3. No mover ni renombrar el original.
4. Compartir la copia para inspección inicial.
5. Inventariar plugins, licencias y assets comprados.
6. Revisar archivos grandes, temporales y datos locales.
7. Definir Git LFS si el volumen de recursos lo requiere.

## Lo que necesitamos inspeccionar
- Archivo `Game.rmmzproject`.
- Carpetas `data/`, `img/`, `audio/`, `js/`, `movies/`, `fonts/` si existen.
- Lista de plugins y orden de carga.
- Versión exacta de RPG Maker MZ.
- Número y nombres de mapas.
- Eventos comunes, switches y variables relevantes.
- Modificaciones propias al código base.
- Recursos con licencia o procedencia externa.

## Precaución
No subir un plugin comprado ni sus archivos fuente hasta comprobar las condiciones de licencia. Podemos documentar nombre, versión y dependencia sin redistribuirlo.
