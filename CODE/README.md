# Código y plugins

Organización propuesta:
- `plugins/owned/` — plugins escritos para Venequia.
- `plugins/patches/` — parches propios documentados.
- `tools/` — scripts y utilidades del equipo.
- `specs/` — especificaciones técnicas.

Los plugins comerciales/de terceros no se copian aquí salvo que la licencia permita su redistribución. Registrar dependencias y versiones en `DOCUMENTATION/TECHNICAL_ARCHITECTURE.md`.
