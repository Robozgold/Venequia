# Hoja de ruta inicial

Las fases se ordenarán después de la auditoría del proyecto real.

## Fase 0 — Protección e inventario
- [ ] Confirmar copia de seguridad.
- [ ] Recibir copia del proyecto MZ.
- [ ] Auditar mapas, eventos, recursos y plugins.
- [ ] Identificar archivos pesados y licencias.
- [ ] Confirmar versión del motor.

## Fase 1 — Definición
- [ ] Completar visión del juego.
- [ ] Validar biblia narrativa y capítulo 1.
- [ ] Documentar sistemas principales.
- [ ] Definir alcance de la primera versión.

## Fase 2 — Estabilización técnica
- [ ] Reproducir el proyecto en entorno limpio.
- [ ] Comprobar plugins y orden de carga.
- [ ] Crear procedimiento de backup y versionado.
- [ ] Establecer pruebas básicas de regresión.

## Fase 3 — Producción
- [ ] Priorizar contenido y sistemas.
- [ ] Planificar arte, audio y narrativa.
- [ ] Implementar por entregas pequeñas.
- [ ] Hacer playtests y registrar incidencias.

## Fase 4 — Preparación de lanzamiento
- [ ] Definir plataformas.
- [ ] Validar rendimiento y compatibilidad.
- [ ] Revisar licencias y créditos.
- [ ] Preparar builds y pruebas finales.

**Nota:** no se asignan fechas ni porcentajes hasta conocer capacidad, alcance y estado real.
